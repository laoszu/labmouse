# Labmouse
Grimmace Scale Prediction in laboratory mice (MGS).

## Installation
```
git clone https://github.com/laoszu/labmouse
cd labmouse
pip install -r requirements.txt
```

## Project Structure
- `data/`
- `Eyes_detection/`
- `Face_detection/`
- `notebooks/`
