# Labmouse

## Overview
Grimmace Scale Prediction in laboratory mice (MGS).

## Installation
```
git clone https://github.com/username/labmouse-grimace-scale.git
cd labmouse-grimace-scale
pip install -r requirements.txt
```

## Requirements
- Python 3.8+
- OpenCV
- TensorFlow 2.x
- NumPy
- Pandas
- Matplotlib

## Project Structure
- `data/`: Training and validation datasets
- `models/`: Trained model files
- `src/`: Source code
  - `preprocess.py`: Image preprocessing utilities
  - `model.py`: Neural network architecture
  - `predict.py`: Prediction functions
- `notebooks/`: Jupyter notebooks for data exploration, modeling and testing
- `docs/`: Documentation
